## 1. 프로젝트 개요

### 카테고리
> 라이프스타일 / 일상

### 주제
소소 (SOSO)

### 배경
현대인들은 빠르게 변화하는 일상 속에서 스트레스와 피로감을 느끼며, 소소한 행복을 놓치기 쉽습니다. 많은 사람들이 자신의 감정이나 일상을 기록하고 싶어 하지만, 긴 글쓰기에 대한 부담감, 기록의 불규칙성, 그리고 기록에 대한 즉각적인 보상 부재 등으로 인해 꾸준히 실천하지 못하는 경우가 많습니다. 또한, 기록된 내용이 단순히 나열되는 것을 넘어, 시각적으로 축적되고 의미 있는 형태로 재조합되어 회고할 수 있는 경험에 대한 니즈가 존재합니다.

### 사용자 문제
사용자들은 자신의 일상 속 작은 행복이나 긍정적인 감정을 기록하고 싶어 하지만, 매일 긴 글을 쓰는 것에 대한 부담, 기록의 지속성 부족, 과거 기록을 효과적으로 회고하기 어려움, 그리고 기록을 통한 시각적인 성취감 부재 등의 문제에 직면합니다.

### 해결 방식
소소는 '기록 → 시각적 축적 → 기다림 → 회고'의 독특한 경험 구조를 통해 문제를 해결합니다. 하루에 한 번 짧은 행복 기록을 '네잎클로버'로 시각화하여 '유리병'에 쌓는 애니메이션을 제공하며, 일정 조건 하에 과거의 행복을 열람하게 하여 사용자가 작은 행복을 발견하고 스스로를 위로하며 기록을 꾸준히 이어갈 수 있도록 돕습니다.

### 차별점
대부분의 기록 서비스는 기록에서 끝나지만, 소소는 '기록 → 시각적 축적 → 기다림 → 회고'라는 독점적인 경험 구조를 제공합니다. 행복 기록을 네잎클로버와 유리병으로 게임화 및 시각화하여 기록에 대한 재미와 동기를 부여하며, 특정 조건 하에 제한적으로 과거 기록을 열람하게 함으로써 회고의 가치를 높이고 예측 불가능한 즐거움을 선사합니다.

### 타겟 사용자
기록의 가치를 알지만 꾸준히 실천하지 못하는 20-30대 (예: 다이어리를 사도 며칠 못 쓰는 사람, 감정 기록을 해보고 싶지만 부담스러운 사람, 긴 글보다 짧은 기록을 선호하는 사람). 감사일기, 마인드풀니스, 셀프케어 루틴 등 작은 감정 기록에 관심이 많은 사용자. 다꾸, 감성 기록, 작은 성취의 축적 등 감성적인 인터페이스와 시각적 만족감을 선호하는 사용자.

### 사용 시나리오
사용자는 앱 설치 후 온보딩을 거쳐 Google 로그인 및 닉네임 입력을 완료하고, 알림 시간을 설정합니다. 매일 알림을 받고 '오늘 나의 소소한 행복은 무엇이었나요?' 질문에 짧게 답변을 기록합니다. 기록된 행복은 홈 화면 유리병에 클로버로 쌓이는 애니메이션으로 나타나며, 클로버 개수를 확인하며 성취감을 느낍니다. 클로버가 10개 이상 쌓이면 하루에 한 번 과거 행복을 랜덤으로 열람하며 추억에 잠길 수 있고, 100개가 가득 찬 유리병의 모든 기록을 한 번에 열람하여 삶의 행복을 회고하고 위로를 받습니다. 필요에 따라 알림 시간이나 닉네임을 설정에서 변경합니다.

### 핵심 목표
사용자가 매일의 삶 속에서 "오늘도 나에게 작은 행복이 있었다"는 사실을 발견하도록 돕고, 시간이 지난 뒤 그 행복들을 다시 꺼내보며 스스로를 위로하고 성취감을 느낄 수 있도록 하는 것입니다. 이를 통해 기록의 꾸준함을 유도하고, 작은 행복의 축적을 시각적으로 제공하여 동기를 부여합니다.

### 핵심 KPI
일일 활성 사용자 (DAU), 일일 기록 완료율, 유리병 완성률, 주간/월간 앱 유지율 (Retention Rate), 행복 열람 기능 사용률, (향후 수익 모델 도입 시) 인앱 구매 전환율.

### 리스크/이슈
하루 한 번 기록 규칙이 사용자 피로도로 이어져 이탈이 발생할 수 있습니다. 사용자가 매일 기록할 '작은 행복'을 찾기 어려워 흥미를 잃을 수 있으며, 유사 앱과의 경쟁에서 차별점을 잃을 수 있습니다. 인앱 구매 모델의 한계와 개인정보 보안 문제 또한 잠재적 위험 요소입니다.

### 사용자 역할
> 일반 사용자

### 디바이스 (기기)
> iOS, Android

## 2. 온보딩 및 최초 실행 흐름

### 2.1 온보딩 순서
1. **앱 소개**: 기록 → 시각적 축적 → 기다림 → 회고 개념 소개
2. **Google 로그인**: 계정 연동 (필수)
3. **닉네임 입력**: 필수 입력
4. **알림 설정**: 행복 기록 알림 시간 설정
5. **홈 화면**: 메인 유리병 화면으로 진입

### 2.2 Google 로그인 실패/취소
- 로그인 취소 시 앱 진입 불가 (백엔드 저장 필수이므로 로컬 모드 미지원)
- 재시도 유도 UI 제공

### 2.3 오프라인
- 네트워크 없을 때: 로컬에 임시 저장 후, 네트워크 복구 시 백엔드 동기화
- 동기화 실패 시 재시도 로직 제공

### 3.1 일일 행복 기록 (Daily Happiness Record)
> **중요도**: 상 | **진행 상태**: 시작전

사용자가 하루에 한 번, '오늘 나의 소소한 행복은 무엇이었나요?'라는 질문에 대한 짧은 답변을 텍스트 형태로 기록할 수 있는 기능입니다. 기록 시간 기준은 사용자가 설정한 알림 시간을 따릅니다.

#### 세부 규칙
| 항목 | 규칙 |
|------|------|
| 하루 기준 | **알림 시간 기준** (예: 09:00 설정 시 09:00~다음날 08:59가 한 하루) |
| 텍스트 길이 | **100자 이내** |
| 빈/최소 기록 | 허용 (공백, 짧은 글 등 사용자 자유) |
| 수정 | 불가 |
| 삭제 | 가능 |

**수용 기준:**
1. 사용자는 하루에 한 번만 행복을 기록할 수 있어야 한다.
2. 기록은 텍스트 입력 필드를 통해 이루어지며, 100자 이내로 제한된다.
3. 저장 버튼을 통해 완료된다.
4. 기록 후 홈 화면으로 이동하며, 클로버가 유리병에 추가되는 애니메이션이 재생된다.
5. 하루 기록이 완료되면, 해당 날짜에 다시 기록할 수 없도록 UI가 변경되어야 한다.
6. 알림 설정 시간을 기준으로 하루의 기록 가능 여부가 초기화되어야 한다.
7. 저장한 기록은 삭제할 수 있어야 하며, 수정은 불가하다.

#### 3.1.1 하루 한 번 기록 제한 기능
사용자가 하루에 한 번만 행복 기록을 할 수 있도록 제한하는 기능입니다. UI는 기록 완료 시 다시 기록할 수 없음을 명확히 표시합니다.

#### 3.1.2 텍스트 입력 및 저장 기능
사용자가 텍스트 필드에 행복 기록을 입력(100자 이내)하고 저장 버튼으로 저장할 수 있는 기능입니다.

#### 3.1.3 기록 완료 후 홈 화면 이동 및 클로버 애니메이션
기록을 완료하면 홈 화면으로 자동 이동하며, 기록된 행복이 네잎클로버 형태로 유리병에 쌓이는 애니메이션을 보여주는 기능입니다. 클로버는 **위에서 떨어져 쌓이는** 방식으로 표시된다.

#### 3.1.4 기록 불가 UI 변경 기능
해당 날짜에 이미 기록했을 경우, 기록 불가 상태임을 UI상에서 명확하게 표시하는 기능입니다.

#### 3.1.5 알림 시간 기준 하루 기록 초기화
사용자가 설정한 알림 시간에 따라 하루 기록 가능 여부를 초기화하는 기능으로, 정확한 시간 기반 기록 관리를 지원합니다.

#### 3.1.6 행복 기록 삭제 기능
저장한 행복 기록을 삭제할 수 있는 기능입니다. 수정은 불가하며 삭제만 지원합니다.

### 3.2 행복 시각화 및 유리병 시스템 (Happiness Visualization & Bottle System)
> **중요도**: 상 | **진행 상태**: 시작전

기록된 행복 하나를 네잎클로버 하나로 시각화하여, 홈 화면의 유리병에 클로버가 쌓이는 애니메이션을 보여줍니다. 하나의 유리병은 최대 100개의 클로버를 담을 수 있으며, 100개가 채워지면 새로운 유리병이 자동으로 생성됩니다. 홈 화면에서 현재 유리병의 클로버 개수를 확인할 수 있습니다.

#### 시각 요소
| 항목 | 규격 |
|------|------|
| 네잎클로버 | 일러스트 (디자이너 제작) |
| 유리병 | 2D 플랫 (일러스트/이미지) |
| 클로버 추가 애니메이션 | 위에서 떨어져 쌓임 |
| 유리병 100개 완성 시 | 축하 애니메이션/이펙트 제공 |

**수용 기준:**
1. 행복 기록 시 유리병에 클로버가 추가되는 시각적 애니메이션이 제공되어야 한다.
2. 홈 화면에 현재 진행 중인 유리병의 클로버 개수가 숫자로 명확하게 표시되어야 한다.
3. 클로버가 100개 모이면 해당 유리병은 '가득 찬' 상태로 간주되며, 축하 애니메이션/이펙트가 재생되고, 새로운 빈 유리병이 자동으로 생성되어 기록이 이어진다.
4. 가득 찬 유리병들은 개별적으로 관리되어 이전 유리병들을 열람할 수 있는 목록이나 형태로 제공되어야 한다.

#### 3.2.1 네잎클로버 추가 애니메이션
행복 기록 시 네잎클로버가 유리병에 **위에서 떨어져 쌓이는** 부드럽고 시각적으로 즐거운 애니메이션을 구현하는 기능입니다.

#### 3.2.2 유리병 클로버 개수 표시
홈 화면에 현재 진행 중인 유리병에 몇 개의 클로버가 쌓여 있는지 숫자로 명확하게 표시해주는 기능입니다.

#### 3.2.3 가득 찬 유리병 자동 생성
하나의 유리병에 클로버 100개가 채워지면, 축하 애니메이션을 재생하고 해당 유리병을 '가득 찬' 상태로 처리한 뒤 새로운 빈 유리병을 자동으로 생성하는 기능입니다.

#### 3.2.4 이전 유리병 열람 (유리병 화면 상세 UX)
가득 찬 유리병들을 **좌우 스와이프**로 탐색할 수 있습니다.

- **현재 유리병**: 아래에 "소소한 행복 열람하기" 버튼 (10개 이상, 하루 1회 랜덤 열람)
- **이전 유리병**: 왼쪽으로 스와이프하여 이동, 아래에 "전체 열람하기" 버튼 (해당 유리병 100개 열람)
- **페이지 인디케이터**: 점 또는 바 형태로 유리병 인덱스 표시

### 3.3 행복 열람 규칙 (Happiness Retrieval Rules)
> **중요도**: 상 | **진행 상태**: 시작전

기록된 행복은 특정 규칙에 따라 열람할 수 있습니다. 클로버 1~9개일 때는 열람 불가. 10개 이상일 때는 하루에 한 번, 오늘 기록한 것을 제외한 과거의 행복 중 하나를 랜덤으로 열람할 수 있습니다. 100개가 채워진 유리병은 해당 병에 담긴 모든 행복 기록을 한 번에 열람할 수 있습니다.

#### 열람 규칙
- **랜덤 1개 열람**: 오늘 기록 직후에도 오늘 기록은 제외하고 과거 기록 중에서만 랜덤 선택
- **전체 100개 열람**: 가득 찬 유리병의 100개 기록을 **여러 번** 열람 가능 (재열람 제한 없음)

**수용 기준:**
1. 클로버 개수가 10개 미만일 경우, 행복 열람 버튼이 비활성화되거나 표시되지 않아야 한다.
2. 클로버 개수가 10개 이상일 경우, 하루에 한 번 '과거 행복 열람' 버튼이 활성화되어야 한다.
3. '과거 행복 열람' 버튼 클릭 시, 오늘 기록한 행복을 제외한 과거 기록 중 하나가 랜덤으로 사용자에게 제시되어야 한다.
4. 한 번 열람한 후에는 해당 날짜의 열람 버튼이 비활성화되어야 한다 (재열람은 다음날 가능).
5. 유리병이 100개의 클로버로 가득 차면, 해당 유리병에 담긴 모든 100개의 행복 기록을 한 번에 열람할 수 있는 기능이 제공되어야 한다.
6. 전체 열람은 여러 번 재열람 가능하다.
7. 열람된 행복은 기록 날짜와 함께 표시되어야 한다.

#### 3.3.1 행복 열람 버튼 활성화/비활성화 기능
유리병의 클로버 개수에 따라 행복 열람 버튼을 활성화하거나 비활성화하는 기능입니다. 클로버 개수가 10개 미만일 경우 버튼을 숨기거나 비활성화하며, 10개 이상일 경우 하루에 한 번 활성화합니다.

#### 3.3.2 과거 행복 랜덤 열람 기능
사용자가 하루에 한 번, 오늘 기록한 것을 제외한 과거 행복 기록 중 하나를 랜덤으로 열람할 수 있는 기능입니다. 열람 후 해당 날짜의 열람 버튼은 비활성화되어 재열람은 다음날 가능하도록 합니다. **쪽지 모양 모달**로 표시합니다.

#### 3.3.3 가득 찬 유리병 전체 열람 기능
유리병에 클로버가 100개 가득 찬 경우, 해당 유리병에 담긴 모든 행복 기록을 한 번에 열람할 수 있는 기능입니다. **쪽지 모양 그리드**로 스크롤 가능하게 표시하며, **여러 번 재열람 가능**합니다.

#### 3.3.4 열람된 행복 기록 및 날짜 표시 기능
열람한 행복 기록과 작성 날짜를 보기 좋은 형태로 사용자에게 표시하는 기능입니다. 기록의 의미를 생생하게 전달합니다.

---

### 3.4 삭제 시 유리병 처리 규칙

행복 기록 삭제 시 유리병 클로버 개수는 **실시간으로 반영**됩니다.

- 삭제한 기록에 해당하는 클로버가 유리병에서 제거된다.
- 100개였던 유리병에서 1개를 삭제하면 99개가 되며, "가득 찬" 상태가 해제된다.
- 99개 유리병은 "전체 열람하기" 대신 "소소한 행복 열람하기"만 제공된다 (10개 이상이므로 랜덤 열람 가능).
- 삭제로 인해 10개 미만이 된 유리병은 행복 열람 버튼이 비활성화된다.

### 3.5 알림 및 설정 (Notifications & Settings)
> **중요도**: 중 | **진행 상태**: 시작전

사용자가 원하는 시간에 맞춰 행복 기록 알림을 설정하고 관리할 수 있습니다. 또한 닉네임 변경 등 기본적인 사용자 설정을 제공합니다.

#### 알림 문구
"오늘 나의 소소한 행복은 무엇이었나요?"

**수용 기준:**
1. 사용자는 앱 내에서 행복 기록 알림 시간을 설정하고 변경할 수 있어야 한다.
2. 설정된 시간에 맞춰 알림 메시지가 발송되어야 한다.
3. 사용자는 자신의 닉네임을 변경할 수 있어야 한다.
4. 기본적인 앱 버전 정보 등을 설정 화면에서 확인할 수 있어야 한다.

#### 3.5.1 알림 시간 설정 UI
사용자가 앱 내 설정 화면에서 행복 기록 알림 시간을 직관적으로 설정하고 변경할 수 있는 인터페이스를 제공합니다.

#### 3.5.2 알림 메시지 발송 기능
설정된 시간에 맞춰 사용자의 기기(iOS, Android)로 행복 기록 알림 메시지를 정확하게 전송하는 시스템 기능입니다.

#### 3.5.3 닉네임 변경 기능
사용자가 설정 화면에서 자신의 닉네임을 쉽게 변경하고 저장할 수 있는 기능으로, 프로필 개인화를 지원합니다. 온보딩에서 필수 입력 후, 이후에는 선택적으로 변경 가능합니다.

#### 3.5.4 앱 버전 및 정보 확인 화면
설정 메뉴 내에서 현재 설치된 앱 버전과 저작권, 개인정보처리방침 등의 기본 정보를 사용자에게 제공하는 기능입니다.

### 3.7 핵심 화면 구조 (Core Screen Structure)
> **중요도**: 상 | **진행 상태**: 시작전

사용자가 앱의 주요 기능을 사용할 수 있도록 홈(유리병), 기록, 열람, 설정 화면을 제공합니다. 각 화면은 사용자 경험 흐름에 맞춰 직관적으로 구성되어야 합니다.

**수용 기준:**
1. **Home (유리병 화면)**: 현재 유리병의 클로버 개수, 오늘 기록 여부, 행복 기록 버튼, 행복 열람 가능 여부가 명확하게 표시되어야 한다. 유리병 애니메이션이 부드럽게 작동해야 한다. 좌우 스와이프로 이전 유리병 탐색 가능하며, 페이지 인디케이터로 위치를 표시한다.
2. **Write Screen (행복 기록 화면)**: '오늘 나의 소소한 행복은 무엇이었나요?' 질문 문구와 텍스트 입력 필드(100자 제한), 저장 버튼이 명확하게 제공되어야 한다.
3. **Memory Screen (행복 열람 화면)**: 열람된 행복 기록과 작성 날짜가 보기 좋게 표시되어야 한다. 랜덤 1개는 쪽지 모달, 전체 100개는 쪽지 그리드로 표시한다.
4. **Settings Screen**: 알림 시간 변경, 닉네임 변경 등 설정 메뉴들이 잘 정리되어 표시되어야 한다.

#### 3.7.1 홈 화면 유리병 애니메이션 최적화
유리병 화면에서 네잎클로버 추가 애니메이션이 부드럽고 자연스럽게 작동하도록 최적화하는 기능입니다. 애니메이션 중 프레임 드랍이나 버벅임 없이 사용자 경험을 향상시킵니다.

#### 3.7.2 행복 기록 텍스트 입력 UI 구성
행복 기록 화면에서 질문 문구('오늘 나의 소소한 행복은 무엇이었나요?'), 텍스트 입력 필드(100자 제한), 저장 버튼이 사용자에게 명확하게 표시되고 사용하기 쉽도록 UI를 구성하는 기능입니다.

#### 3.7.3 행복 열람 화면 레이아웃 제공
행복 열람 화면에서 열람된 행복 기록과 작성 날짜를 보기 좋게 배치하여 사용자가 편안하게 과거 기록을 회고할 수 있도록 하는 레이아웃 기능입니다. 랜덤 1개는 쪽지 모달, 전체 100개는 쪽지 그리드로 제공합니다.

#### 3.7.4 설정 화면 메뉴 구성 및 접근성 개선
알림 시간 변경, 닉네임 변경 등 설정 관련 메뉴를 한눈에 보기 쉽게 구성하고, 각 메뉴로 빠르게 이동할 수 있는 접근성 높은 UI를 제공합니다.
